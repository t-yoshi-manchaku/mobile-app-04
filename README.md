# Assignment Template

このリポジトリは **GitHub Classroom の課題提出用テンプレート**です。  
各 Assignment では、このテンプレートから **学生ごとのリポジトリ**が作成されます。

---

## 📌 このリポジトリの使い方

- このリポジトリ自体は **編集しません**
- 各授業の課題は、このテンプレートを元に **自動生成**されます
- 学生は、生成された **自分専用のリポジトリ**を編集してください

---

## 📂 ディレクトリ構成
```text
.
├─ README.md      ← 学生が編集する（課題提出の本文）
├─ src/           ← ソースコード・スクリプト
├─ data/          ← データファイル（CSV / JSON など）
├─ images/        ← スクリーンショット・図
└─ Feedback/      ← 教員からのフィードバック
```


---

## 🧑‍🎓 学生向けガイド（重要）

### 課題の提出方法
1. Classroom のリンクから Assignment に参加
2. 作成された **自分のリポジトリ**を開く
3. この `README.md` を編集して課題内容を記入
4. 必要に応じて `src/` や `images/` を追加
5. Commit & Push で提出完了

---

## ✏ README.md 記入項目（例）

以下の項目を参考に、**自分の言葉で**記入してください。

- 氏名 / 学籍番号
- 課題の目的
- 実施内容
- 成果物
- 気づいたこと・学んだこと

※ 課題ごとの詳細指示は、Assignment ページに記載されます。

---

## 👩‍🏫 教員向けメモ

- フィードバックは `Feedback/README.md` に記入します
- 採点・コメントは Commit 履歴も含めて行います

---

## ⚠ 注意事項

- 他人のリポジトリをコピーしないこと
- 生成AIを使用した場合は、その旨を README に明記してください
- このテンプレートは **全科目共通**です

---

## 📘 このテンプレートの目的

- 課題提出の形式を統一する
- 成果物だけでなく **学習プロセスを残す**
- GitHub を「提出箱」ではなく **学習ログ**として使う
